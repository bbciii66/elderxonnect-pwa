# ElderXonnect

Elder care companion PWA with a shared Care Circle for the elder, family and onsite caregivers.
See `V2-NOTES.md` for what the v2 rebuild changed, how to apply the database migration, and what is still open.

Run all checks: `npm test` (needs Node 22, Playwright with Chromium, and local Postgres 16 binaries). Made-up people only.
